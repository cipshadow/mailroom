Step 1 — Your Google key {% if step > 1 %}done{% endif %}

{% if step == 1 %}

Kindle Mailroom reads and sends mail as you, using a key only you hold. Creating it is free and takes about five minutes. Each link opens the right page in Google Cloud — do them in order:

  1. Create a project — any name will do (e.g. kindle-mailroom). Make sure it's selected before continuing.
  2. Enable the Gmail API → click Enable.
  3. Set up the consent screen → Get started; give it a name, use your own email, and choose audience External. Then open Audience → Test users → Add users → add your own Gmail address.
  4. Create the client → application type Desktop app → Create → Download JSON. That file is what you paste below.

Google rearranges this console fairly often. If a link 404s, open console.cloud.google.com, check your project is selected, and search for “Gmail API”, “Google Auth Platform” or “Credentials”. The full written guide has more detail.

What can this app see, and why my own key?

It asks for exactly two Gmail permissions: gmail.modify (read your mail and change labels, so it can find labelled emails and file them once sent) and gmail.send (email the EPUB to your Kindle). Nothing else, and nothing leaves your machine except those Gmail calls.

There's no server behind this app, so there's no shared key it could use. Your own OAuth client means only you can authorise access to your mail.
